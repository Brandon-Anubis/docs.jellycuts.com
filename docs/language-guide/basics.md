# The Basics

Jelly is an extremely simple language that pulls inspiration from **Swift** and **JavaScript** for most of its syntax. However, some parts of the language such as *Metadata* are Jelly-specific. If you already know one of these languages, learning Jelly should feel familiar. If you don’t, this guide will walk you through everything you need to know.

## How to go through this guide

A good starting point is the tutorial **[Writing Your First Script](../getting-started/writing-first-script.md)** in the Getting Started section. After you have written a simple script, come back here for topics you want to explore further.
