# Language Overview

The Jelly language was created for [Siri Shortcuts](https://apps.apple.com/us/app/shortcuts/id915249334) because [I](https://actuallyzach.com) was not satisfied with the GUI of Shortcuts. I wanted a way to write Shortcuts in a text-based language. That is why I created [Jellycuts](https://jellycuts.com) and the Jelly language.

The Jelly language is currently focused on creating a simple way to write Shortcuts without much hassle. The language is geared towards calling the Shortcuts actions as functions. However, in the future I plan to alter the way the language is interpreted so you are able to write code in a [Swift](https://www.swift.org) or [JavaScript](https://www.javascript.com)-like fashion and have it translated into a Shortcut — or even write and compile it like any other language.

## Getting started

The first place to start is setting up your IDE. The current IDE for Jelly is the [Jellycuts iOS App](https://jellycuts.com).

Once you have set up your IDE you can head over to **Writing Your First Script** to learn how to write your first Jellycut script.
